# Affiches de la série — réseaux sociaux

- `visuel-A-souvenir` : H sur un toit de Marrakech au coucher du soleil, Béa en souvenir dans le ciel.
- `visuel-B-ruelle` : H et Béa se croisent dans une ruelle de la médina, la nuit.

Les titres sont posés par `affiches.py` en vraie typographie (Playfair Display, Cormorant Garamond, Amiri pour l'arabe) : pas de fautes de texte comme avec l'IA.

Pour chaque visuel : 3 langues (français, darija, anglais) × 4 formats
(story 1080×1920 pour TikTok, Reels et Stories · post 1080×1350 pour Instagram · carré 1080×1080 · YouTube 1920×1080).

```
python3 affiches.py visuel-A-souvenir.png sortie/affiche-A
```
