# Publitarium Events — thème WordPress

Variante WordPress de Publitarium Events (palette « Majorelle »), prévue pour https://events.almoqayada.com.

## Installation
1. Apparence > Thèmes > Ajouter > Téléverser : `publitarium-wp.zip`, puis Activer
   (ou déploiement Git dans `wp-content/themes/publitarium-wp`).
2. À l'activation, le thème crée les rubriques, les villes, les pages « Favoris » et « À propos »,
   règle les permaliens sur /%postname%/ et importe le contenu de départ (une seule fois).

## Gérer le contenu (administration WordPress)
- **Agenda & festivals** : événements, festivals et rendez-vous (dates, lieu, tarif, créneaux, lien).
  Remplir « Créneaux » affiche le formulaire de réservation.
- **Articles** : champ « Résumé vocal d'Oulbig » (texte lu par le navigateur) ou
  « Enregistrement audio » (MP3 de la médiathèque, prioritaire).
- **Bonnes adresses**, **Rubriques** (couleur et icône), **Villes**.
- **Rendez-vous reçus** et **Newsletter** : demandes envoyées depuis le site, export CSV.
  Chaque rendez-vous est aussi envoyé par e-mail à l'adresse de l'administrateur.
- Photos : « Image mise en avant » de chaque contenu.

## Couleurs
Apparence > Personnaliser > **Couleurs Publitarium** : 6 palettes (Majorelle, Medina Pop,
Terracotta, Atlantique, Safran nuit, Menthe fraîche) ou couleurs libres, mode sombre par défaut,
phrase du pied de page.
